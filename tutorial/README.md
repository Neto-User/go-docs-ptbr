# Tutoriais

> Tradução não oficial de [go.dev/doc/tutorial](https://go.dev/doc/tutorial/).

Se você é novo em alguma parte do Go, dê uma olhada nos tutoriais abaixo.

Se ainda não instalou o Go, veja [Download e instalação](https://go.dev/doc/install).

| Tutorial | Descrição |
| --- | --- |
| [Primeiros passos](getting-started.md) | Diga Hello, World com Go. |
| [Crie um module](create-module.md) | Tutorial em várias partes que apresenta recursos comuns de linguagens de programação do ponto de vista do Go. |
| [Primeiros passos com workspaces multi-module](workspaces.md) | Apresenta o básico de como criar e usar workspaces com vários modules em Go. Workspaces multi-module são úteis para fazer mudanças em vários modules ao mesmo tempo. |
| [Trabalhando com JSON](json.md) | Apresenta o básico de como trabalhar com JSON usando a standard library. |
| [Acessando um banco de dados relacional](database-access.md) | Apresenta o básico de como acessar um banco de dados usando a standard library. |
| [Desenvolvendo uma API RESTful com Go e Gin](web-service-gin.md) | Apresenta o básico de como escrever uma API de web service RESTful com Go e o Gin Web Framework. |
| [Primeiros passos com generics](generics.md) | Apresenta o básico de generics em Go. Com generics, você pode declarar e usar funções ou tipos escritos para funcionar com qualquer tipo de um conjunto fornecido pelo código que os chama. |
| [Primeiros passos com fuzzing](fuzz.md) | Apresenta o básico de fuzzing em Go. O fuzzing gera entradas para os seus testes que podem pegar casos extremos (edge cases) e problemas de segurança que você talvez não tenha percebido. |
| [Primeiros passos com govulncheck](govulncheck.md) | Mostra como encontrar e corrigir vulnerabilidades com o govulncheck. O govulncheck reporta vulnerabilidades conhecidas que afetam código Go. |
| [Encontre e corrija dependências vulneráveis com o VS Code Go](govulncheck-ide.md) | Mostra como encontrar e corrigir dependências vulneráveis direto da sua IDE, com VS Code Go e Vim. |
| [A Tour of Go](https://go.dev/tour/) (externo, em inglês) | Uma introdução interativa ao Go: sintaxe básica e estruturas de dados; métodos e interfaces; e as primitivas de concorrência do Go. |
